## Bulk conversion

Squishy now works on batches instead of one file at a time.

- Drop or choose **many files at once**. They appear as a queue list with a thumbnail, size, duration and resolution for each item.
- **Five exports run in parallel**; the rest wait their turn and start automatically as slots free up.
- Per-file progress, status and errors in the list, plus overall progress and a running/waiting count.
- Cancel the whole queue, or cancel and remove individual files from the right-click menu.
- Colliding output names are numbered automatically (`clip.png` and `clip.psd` exporting to PNG no longer overwrite each other).
- A **Destination** control writes everything to one folder, or leaves each file alongside its original.

## Console

Click the status strip at the bottom to open a console with timestamped entries for every job: what started, what it produced (with the size change), and the ffmpeg error output for anything that failed. Copy the whole log to the clipboard in one click.

## Updates

Squishy now checks GitHub for new releases on launch (at most once a day) and offers to open the download page. You can also trigger it from **Squishy ▸ Check for Updates…**.

## Fixes

- Dropping files onto the URL field inserted their paths as text instead of queueing them.
- Long text could break the window layout.
- Adding many files no longer freezes the UI while metadata is read.
- Lossless formats now say **Convert** rather than Compress, and hide the quality slider that had no effect.
- Image exports pass `-update 1`, silencing an ffmpeg warning.

---

**Installing:** download the `.dmg`, drag Squishy into Applications, replacing any older copy. Squishy still needs Homebrew, FFmpeg and yt-dlp; the first-run screen installs them for you.
